# civ6-leader-mod — скилл Claude для сбалансированных модов на лидеров Civilization VI

Скилл для [Claude Code](https://claude.com/claude-code), который помогает вручную, без ModBuddy (работает и на macOS), сделать мод на правителя (лидера) или цивилизацию для Sid Meier's Civilization VI. Главное в нём — **проверка баланса**: прежде чем писать код, Claude сверяет каждую способность с цифрами официальных лидеров. Если идея имбалансная, он предупредит, объяснит, что именно ломает игру, и предложит сбалансированный вариант. Решение всегда остаётся за тобой: скилл советует, а не запрещает.

## Установка

```bash
git clone https://github.com/darkhan-amanbek/civ6-leader-mod.git ~/.claude/skills/civ6-leader-mod
```

Перезапусти Claude Code. Скилл включится сам, когда ты попросишь что-то вроде:

- «Хочу сделать мод на лидера: Чингисхан для Монголии, конница сильнее»
- «Придумай лидера-учёного для Греции, чтобы не было имбы»
- «Проверь мой мод, лидер не появляется в списке»
- «+3 науки с каждой клетки — это не имба?»

Обновление: `cd ~/.claude/skills/civ6-leader-mod && git pull`.

|---|---|

| `references/balance.md` | Правила баланса: бюджет силы, 4 оси оценки, реальные цифры официальных лидеров и уникальных юнитов, красные флаги, приёмы ослабления, разобранные примеры |
| `references/modifiers-cookbook.md` | Проверенные рецепты модификаторов: доходы, производство, сила юнитов с условием, выплаты, эврики, слоты политик |
| `references/schema.md` | Таблицы базы игры: лидер, ИИ и повестки, экран выбора, новая цивилизация, уникальные юнит, район и здание |
| `references/mod-structure.md` | `.modinfo`, FrontEnd/InGame, базовая игра и дополнения, форматы SQL/XML, пути на Mac/Windows, что реально с графикой |
| `references/testing.md` | Логи, чек-лист проверки в партии, частые ошибки |
| `templates/leader-for-existing-civ/` | Рабочий шаблон мода: Марк Агриппа для Рима, с баланс-карточкой |
| `scripts/validate_mod.py` | Проверка мода до запуска игры: манифест, тексты, пробный прогон на копии базы игры, подсказки по балансу |
| `scripts/find_examples.py` | Поиск, как Firaxis сделала похожую механику (модификаторы, требования, трейты) |

Скриптам нужен только Python 3.8+. Пробному прогону и поиску нужна база игры: она появляется после того, как ты хотя бы раз запустишь партию.

## Правила баланса коротко

1. **Бюджет:** у лидера одна сильная механика и одна мелочь. Если в описании больше трёх пунктов «а ещё…», это почти наверняка перебор.
2. **Чем уже охват и жёстче условие, тем больше может быть число.** +50% к одному классу юнитов — норма (Харальд), +10% ко всем доходам везде — уже сильно.
3. **Ранние бонусы копятся:** +1 с первого хода стоит дороже, чем +3 в поздней игре.
4. **Уникальный юнит:** +3…+5 силы, **или** +1 ход, **или** особая способность, и часто дороже базового. Сильнее, быстрее и дешевле одновременно — имба.
5. **Красные флаги:** регулярные бесплатные технологии или юниты, проценты ко всем доходам без условия, бесконечное масштабирование, неуязвимость, разовые выплаты без масштабирования по скорости игры.
6. **ИИ** понимает только модификаторы и свои предпочтения (`AiFavoredItems`), а Lua-механики не понимает вовсе.
7. **Мультиплеер:** у всех игроков должен стоять мод одной версии.

Подробно — в [references/balance.md](references/balance.md).

## Ограничения

- Анимированный 3D-лидер без инструментов Firaxis (только Windows) недостижим. Реально сделать статичный портрет или взять иконку существующего лидера.
- Новый игровой эффект (`EffectType`) создать нельзя: он зашит в движок. Механики собираются из существующих.
- Правила баланса — это ориентиры, выведенные из официальных лидеров и практики сообщества, а не официальный стандарт Firaxis.
