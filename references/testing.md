# Проверка и отладка

## 1. До запуска игры

```
python3 scripts/validate_mod.py "<папка мода>"
```

Что проверяет:
1. `.modinfo` — корректный XML, GUID, все файлы из действий есть на диске и в `<Files>`, нет лишних.
2. Все XML-файлы корректны.
3. Каждый `LOC_*`, на который ссылается мод, определён в его текстах или в игре; у каждого тега есть `en_US`.
4. **Пробный прогон**: копирует кэш БД игры во временный файл и применяет SQL/XML мода с включёнными внешними ключами. Ловит опечатки в именах таблиц и столбцов, ссылки на несуществующие типы, дубли.
5. **Подсказки по балансу**: сравнивает уникальные юниты с заменяемыми, отмечает крупные числа без условий, рискованные типы модификаторов.

Флаги: `--no-dry-run` (пропустить прогон), `--cache <путь>` (свой путь к кэшу).

Ограничения прогона: кэш — это база **последней** партии. Если в ней уже был этот мод, прогон покажет «дубли» — это нормально (скрипт предупредит). Если последняя партия была в другом ruleset, ссылки на контент дополнений могут не найтись.

## 2. Установка

1. Скопируй папку мода в каталог модов (пути — `mod-structure.md` §1).
2. Игра → **Дополнительный контент** (Additional Content) → **Моды** → включи мод.
3. Создай одиночную игру → выбери лидера. Если лидера нет в списке — проблема во FrontEnd-части (`Players`, `Domain`, текст).

## 3. Логи

Перед проверкой удобно очистить логи (или смотреть время изменения). После запуска партии:

| Лог | Что искать |
|---|---|
| `Modding.log` | Загрузился ли мод, какие действия и файлы применены. Если файла нет в логе — его нет в `.modinfo` |
| `Database.log` | `Error`, `no such table`, `no such column`, `FOREIGN KEY constraint failed`, `UNIQUE constraint failed`. **Любая ошибка в SQL-файле останавливает весь этот файл** — всё после неё не загрузится |
| `GameEffects.log` | Ошибки модификаторов: неверный `ModifierType`, аргумент, требование |
| `Lua.log` | Ошибки Lua-скриптов (если есть) |

Быстрый поиск (macOS):
```
cd ~/Library/Application\ Support/Sid\ Meier\'s\ Civilization\ VI/Firaxis\ Games/Sid\ Meier\'s\ Civilization\ VI/Logs
grep -n -i -E "error|failed|XYZ" Database.log Modding.log GameEffects.log | tail -50
```

## 4. Чек-лист в партии

- [ ] Лидер есть на экране выбора, имя, описание способности и иконка отображаются (без `LOC_...`).
- [ ] Партия стартует, не выкидывает в главное меню (выкидывание = ошибка в InGame-БД, смотри `Database.log`).
- [ ] Цивилопедия → лидер: способность описана.
- [ ] Эффект **виден в цифрах**: доход в городе/клетке, предпросмотр боя показывает строку способности, производство района быстрее и т.п. Описание в тексте ≠ работающий модификатор — проверяй каждый эффект.
- [ ] Эффекты с условием: проверить случай, когда условие выполнено, и когда нет.
- [ ] Для мультиплеера: партия на 2+ игроков с модом, несколько ходов без рассинхронизации.
- [ ] Отдать лидера ИИ на 50+ ходов (автоигра / наблюдатель) — не ломается ли игра, развивается ли ИИ.

## 5. Частые ошибки

| Симптом | Причина |
|---|---|
| Лидера нет в списке | `Players` не во FrontEnd, нет строки для нужного `Domain`, ошибка в Config-файле |
| При старте партии — назад в меню | Ошибка в InGame SQL/XML (часто внешний ключ: тип не объявлен в `Types`, опечатка в `TRAIT_...`) |
| Вместо текста `LOC_...` | Тега нет в Text-файле, нет строки для языка клиента, Text не подключён в этой части (FrontEnd/InGame) |
| Способность описана, но не работает | Модификатор уровня города/юнита в `TraitModifiers` без обёртки; неверное имя аргумента; условие никогда не выполняется. Смотри `GameEffects.log` |
| Доход на клетке не виден | Клетка не принадлежит игроку — интерфейс не показывает |
| Половина контента не загрузилась | Ошибка в середине SQL-файла останавливает остаток файла |
| Мод конфликтует с другим | Одинаковый `Mod id` или одинаковые идентификаторы без префикса |
| Юнит невидим на карте | Нет арта для `UNIT_...` — нужен `.artdef`/`.dep`, наследующий модель заменяемого |

## 6. Необязательно: проверка через FireTuner / civ6-mcp

Если у тебя есть доступ к живой игре через FireTuner (например, MCP-сервер `civ6-mcp` с инструментом `run_lua`), можно проверить загрузку прямо в партии:
```lua
print(GameInfo.Leaders["LEADER_XYZ"] ~= nil)
for row in GameInfo.TraitModifiers() do if row.TraitType == "TRAIT_LEADER_XYZ" then print(row.ModifierId) end end
print(PlayerConfigurations[0]:GetLeaderTypeName())
```
FireTuner включается в `AppOptions.txt` (`EnableTuner 1`); в сетевом мультиплеере не работает.
